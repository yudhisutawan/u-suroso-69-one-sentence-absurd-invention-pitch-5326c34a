One-sentence absurd invention pitch for make.fun's "One-Sentence Absurd Invention Pitch" bounty ($2.50 prize pool, top 10). The program writes a single pitch — a printer that prints a formal excuse note for every page it refuses to print, signed in Comic Sans by its manager, the scanner — to `entry.txt`. The pitch is the winner of a 10-candidate head-to-head tournament judged with the competition's own judge brief: undefeated (9 wins, 0 losses).
